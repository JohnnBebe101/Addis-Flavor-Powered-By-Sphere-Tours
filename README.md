# Addis Ababa City Tours

Explore Addis Ababa's authentic culture, cuisine, and nearby day trips. Book private cooking classes, traditional coffee ceremonies, and home-cooked meals with vetted local host families.

## Tech Stack

- React 19 + TypeScript
- Vite 6
- Tailwind CSS v4
- Lucide React icons

## Run Locally

**Prerequisites:** Node.js 20+

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000)

## Build for Production

```bash
npm run build
```

Output is in `dist/`.

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server on port 3000 |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |
| `npm run lint` | Type-check with TypeScript |
